# Gruppegenerator - NEST

En simpel og pædagogisk gruppegenerator udviklet med fokus på struktur og "low arousal" (f.eks. til NEST-klasser). Bygget med ren HTML, CSS (Tailwind) og JavaScript.

## Kom i gang
Åbn blot `index.html` i din browser. Der kræves hverken server eller bygge-proces.

## Nøglefunktioner
- **Fleksibel fordeling:** Vælg ud fra antal grupper eller antal elever pr. gruppe.
- **Lodtrækning:** Kan køre automatisk eller lade eleverne trykke.
- **Low arousal:** Slå nemt lyde, animationer og konfetti til eller fra efter behov.
